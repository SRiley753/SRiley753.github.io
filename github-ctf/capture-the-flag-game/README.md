# Capture the Flag Game

Welcome to the Capture the Flag game! This is an interactive quiz-style game where players answer questions to receive clues for the next question. The objective is to solve all the questions and reach the final clue.

## Game Overview

In this game, players will be presented with a series of questions. Each correct answer will provide a clue that leads to the next question. The game continues until all questions are answered.

## How to Play

1. Open the `index.html` file in your web browser.
2. Read the question displayed on the screen.
3. Enter your answer in the provided input field.
4. Submit your answer to receive a clue for the next question.
5. Continue answering questions until you reach the final clue.

## Setup Instructions

To set up the project locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/capture-the-flag-game.git
   ```
2. Navigate to the project directory:
   ```
   cd capture-the-flag-game
   ```
3. Open the `src/index.html` file in your web browser to start playing.
